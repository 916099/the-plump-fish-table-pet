# 大肥鱼桌宠 🐋（开源版 · silveryee 改写）

DeepSeek V4 Pro 二创形象「鲸鱼娘·大肥鱼」的透明桌面宠物。
基于三视图素材（正面 / 侧面 / 背面），用 Python + PySide6 实现，无边框透明置顶窗口。

> **这是二创改写版，不是原创。** 上游两位原作者与本次改写的完整说明见
> **[溯源与致谢.md](溯源与致谢.md)**：
> - 骨架 / 立绘 / 台词 / 交互来自 **[1190fasheqi/dafeiyu-pet](https://github.com/1190fasheqi/dafeiyu-pet)**
> - 动画链思路 + 106 个透明 webm 素材来自 **[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)**

## 🚀 快速开始（第一次用，照着做 5 步）

```bash
# 1) 装依赖（需要 Python 3.11+）
pip install -r requirements.txt
```

2. **启动**：双击 `启动桌宠.bat`，或者命令行 `python 桌宠.py`。
   屏幕上会出现一只透明的小鱼（第一次会出现在屏幕右下角附近）。
3. **设置 Key**：**右键点鱼** →「**设置 Key（还没填 ← 点这里）**」→ 粘贴你的 DeepSeek Key → 确定。
   气泡会报「Key 验过了 ✓」。**不用重启。**
   （Key 去 <https://platform.deepseek.com> 申请）
4. **点一下鱼**：蹦跳 + 回嘴 + 冒出一个 🗨️，点它打开**分身窗口**。
5. **在分身窗口里说话**：底部输入框打字，按 Enter 发送。要它查东西就直接说，例如
   「帮我查一下 PySide6 最新的稳定版本，给出来源」。

> 只想养鱼不想用 AI？**完全不用填 Key** —— 散步、拖拽、喂食、动作、护眼提醒全都能用，
> 只有「分身」相关功能会提示你先设置 Key。

### 一分钟认识操作

| 操作 | 效果 |
|---|---|
| **左键单击** | 蹦跳 + 回嘴 |
| **左键双击** | 喂食面板（小鱼干 / 蛋糕 / 棒棒糖 / 团子 / 钻石） |
| **左键按住拖** | 拖拽，鱼会侧身朝向你拖的方向；甩得够快会飞出去、撞墙反弹 |
| **右键** | 完整菜单（所有设置都在这儿） |
| **托盘图标** | 右键 = 同款菜单；左键 = 显示 / 隐藏 |
| **窗口不见了** | 右键托盘图标 →「显示/隐藏」，或「回到屏幕内」 |

## 🔐 隐私与个人配置（先看这一节）

**这个仓库里没有任何人的真实密钥。** 配置模板 `config.example.json` 里写的是占位符：

```json
"ds_api_key": "我的API key 填充sk……"
```

### 我的个人配置在哪？（检查位置）

**配置不在程序目录里**，而是在你自己的 Windows 账户下 —— 这样程序文件夹怎么传、怎么装到
`Program Files`，都不会带走你的设置和 Key：

| 要查的东西 | 位置 |
|---|---|
| **个人配置文件**（城市 / 模型 / 主题 / 窗口位置…） | `%APPDATA%\dafeiyu-pet\config.json`，例如 `C:\Users\<你的名字>\AppData\Roaming\dafeiyu-pet\config.json` |
| **你的 API Key（加密存放）** | 同目录下的 **`key.bin`**，用 Windows DPAPI 按**当前用户**加密 |
| 想看**确切路径** | 右键桌宠 →「**我的配置存在哪？（看路径）**」，弹窗直接给出两个绝对路径 + 掩码状态 |
| 想**直接打开** | 右键桌宠 →「**打开配置文件所在文件夹**」（自动选中 `config.json`） |
| 配置模板（可安全公开） | 仓库里的 **`config.example.json`** |
| 提交前自检 | `python tools/check_privacy.py` |

**想换成"配置跟程序文件夹走"（U 盘随身带）？** 在程序目录里放一个**空的 `portable.txt`** 即可。
这是显式选择，不会默认发生 —— 默认永远是安全的那一边。

**如果你有老版本（配置在程序目录）**：第一次运行本版会**自动搬家**到 `%APPDATA%`，
并把老文件里的明文 Key 加密收进 `key.bin`，同时在老位置留一份**去掉 Key** 的
`config.json.migrated.bak` 备份。搬完气泡会提示「配置已搬到系统用户目录」。

### 为什么不会泄露 / 别的用户会怎样

1. **配置和 Key 都在你自己的 Windows 账户下** —— Windows 的 ACL 天然按用户隔离，
   同一台电脑上的其它账户读不到你的配置。
2. **Key 是加密的** —— `key.bin` 由 Windows DPAPI 按当前用户加密，
   **换台电脑或换个 Windows 账户就解不开**。文件被拷走、同步到网盘、进备份都没用。
   > 说清边界：DPAPI 挡不住"以你的身份运行的恶意程序"（那种程序照样能解密）。
   > 它的作用是**降低误泄露概率**（误打包、网盘同步、文件被拷走），不是绝对安全。
3. **`config.json` 和 `key.bin` 都在 `.gitignore` 里** —— 正常的 `git add` / `git commit` 抓不到。
4. **仓库里只有 `config.example.json`（占位符）** —— 真 Key 只存在于你自己的电脑上。
5. **每个用户各存各的** —— 别人克隆下来，在自己电脑上填自己的 Key，程序自动在**他那台机器**生成自己的配置。
   不需要改代码、不需要重新打包、不影响你。
6. **Key 不完整回显** —— 菜单 / 气泡 / 弹窗里只显示 `sk-***abcd（35 位）` 这种掩码形式，
   截图分享求助不会连 Key 一起发出去。
7. **Key 只发给 DeepSeek 官方 API** —— 桌宠不会把它上传到其它任何地方。

### 设置 Key：**填完即生效，不用重启** ⭐

- 右键桌宠 →「**设置 Key（还没填 ← 点这里）**」→ 粘贴 → 确定。
  程序会**立刻生效**，并用系统加密存进 `key.bin`，然后后台真连一次 API 验活，气泡报结果：
  - `Key 验过了 ✓ 现在就能使唤我`
  - `Key 被拒了（401），检查有没有粘错`
  - `Key 没验成（超时），但不影响使用`
- **手工改 `config.json` 也会自动热加载**：记事本改完一保存，桌宠气泡提示「配置已自动更新：…（不用重启）」。
  （城市 / 模型 / 主题这些都能这么改；Key 建议还是走菜单，它会自动加密。）
- 粘错了不用重启：再点一次「设置 Key」覆盖即可。
- 想单独再验一次：右键 →「**测试 Key 连通性**」。

> **技术上为什么真的不用重启？**
> 上游 `TaskWorker.__init__` 里是 `self.cfg = dict(cfg)` —— 拿的是配置的**拷贝**，
> 所以「任务跑起来之后再换 Key」那个正在跑的任务会一直用旧 Key。
> 本版把上游这个洞补掉了：`apply_key()` 会写内存 → **加密落盘** → 同步联网设置 → 清缓存，
> 并且**主动把新 Key 塞进正在运行的 worker**（`worker.cfg["ds_api_key"] = key`）。
> 另外新增 `QFileSystemWatcher` 监听 `config.json`，外部改动自动热加载；
> 用「写盘后记指纹」的办法区分「自己写的」和「别人改的」，不会自己触发自己。

## 功能

- **三视图行走**：左右走用侧面（自动镜像）、向上走用背面、向下走用正面
- **三种模式**：自由散步 / 跟随鼠标 / 原地待着（右键菜单切换）
- **互动**：
  - 左键按住：拖拽（会侧身朝向拖动方向，松手会说话）
  - 单击：蹦跳 + 回嘴
  - 双击：喂食面板（小鱼干 / 蛋糕 / 棒棒糖 / 团子 / 钻石）
  - 右键：完整菜单（模式 / 大小 / 喂食 / 说句话 / 显示隐藏 / 鼠标穿透 / 置顶 / 开机自启 / 主题 / 护眼 / 动作点播 / 退出；托盘右键同款）
- **台词系统**：日常随机台词 + 互动回嘴 + 思维链心声（灰色斜体括号气泡，小概率冒出），取材自社区 DS 梗
- **17 个动作 + 加权随机链**：摇摆 / 漂浮踏步 / 东张西望 / 伸懒腰 / 敲桌面 / 转身 / 抖水 / 360° 旋转展示 /
  照镜子 / 开心跳 / 害羞 / 打招呼 / 鼓成一团 / 被挠痒 / 思考 / 垂头叹气 / 垂头。
  改 `ACTIONS` 表里的 `weight` 就能调频率
- **拖着甩出去**：松手速度够大就抛物线飞出去、屏幕四边反弹、空气阻力 + 落地摩擦、落地 Q 弹
- **视频动画版**：106 个 VP9-alpha 透明 webm（`anim/`），优先由后台 FFmpeg 原生解码，缺少 FFmpeg 时使用隐藏的 Chromium；透明帧直接画在桌宠本体窗口；
  `config.json` 里 `video_anim: false` 或 `anim/` 没素材时自动退回手绘立绘
- **AI 分身（一个窗口全搞定）**：对话 / 干活 / 看网页都在同一个窗口
  - 工具：`web_search`（DDG + Bing 双源合并去重）、`fetch_url`（读网页原文），最多来回 4 轮（`task_max_rounds`）
  - 内嵌真 Chromium：UA 伪装、Cookie 持久化、能开本地文件 / 下载 / 看 PDF / 弹窗 / 全屏；
    摄像头麦克风等敏感权限一律拒绝并记录（隐私优先）
  - 遇到要登录的站点走**网站自己的登录页**，登录完自动重试继续干活；**桌宠不做登录界面、不保存账号密码**
- **按出口 IP 自动收集线路**：自动探测直连 / 系统代理 / `proxy_list` / 本地常见端口，标出境内外和延迟，
  境外目标走境外线路、国内目标走国内线路，并在两条线路上同时打、谁先出结果用谁
- **护眼骚扰**：默认每 2 小时提醒休息，把你的窗口全收起来，10 分钟后自动放回；
  期间桌宠变成霸屏护眼大屏，输入「我在忙 / 有事 / 下次 / 忙 / skip」可立刻逃生；
  中途重启也不怕（`eye_rest_pending` / `eye_rest_restore_at` 存在配置里）
- **天气查询**：`wttr.in`，有定位坐标优先用坐标（比城市名准）
- **定位**：右键「🌍 用系统定位（授权）」走 Windows 设备级定位；拿不到就退回 IP 粗略定位；
  `auto_locate_city` 默认开，启动 7 秒后静默用 IP 更新城市
- **系统状态监控**：CPU > 90%、内存 > 95%、NVIDIA 显卡温度 > 80°C 时冒泡提醒（间隔 10 秒）
- **主题**：粉色（默认）/ 跟随系统，切换即时生效
- **细节**：呼吸 / 摇摆 / 蹦跳 / 进食动画、转向交叉淡化、加减速惯性、散步自动休息、说话冷却
- **稳定性**：
  - **配置即刻存盘**：Key / 城市 / 模式 / 大小 / 穿透 / 置顶 / 位置一改就写回 `config.json`
    （先写临时文件再原子替换），关机、重启、被任务管理器强杀都不会丢
  - **单实例锁**：同时只允许跑一只，避免两个实例互相覆盖配置
  - **Key 保护**：自己手里没有 Key、磁盘上却有，写盘时绝不冲掉它，反而会取回内存
  - **老配置自动补齐**：配置缺字段时用默认值补上，还原成旧版本也不丢功能
  - **关机道别**：收到 `WM_QUERYENDSESSION` / `WM_ENDSESSION` 先道别并落盘

## 🎮 操作指引（怎么用）

### 右键菜单速查

右键**鱼身**和右键**托盘图标**是同一个菜单。菜单分几块：

| 分区 | 有什么 |
|---|---|
| **本体** | 模式（自由散步 / 跟随鼠标 / 原地待着）、大小（小 / 中 / 大）、动作、视频动画、主题、显示/隐藏、回到屏幕内、鼠标穿透、窗口置顶、开机自启、退出 |
| **护眼** | 护眼提醒（每 2 小时）开关 |
| **Key / 配置** | 设置 Key、测试 Key 连通性、我的配置存在哪？（看路径）、打开配置文件所在文件夹 |
| **天气 / 定位** | 🌍 用系统定位（授权）、设置城市（手动）、启动时自动更新城市（IP）、查看天气 |
| **分身** | 分身（打开窗口）、分身：总结剪贴板 |

> ⚠ **别把自己点不到**：勾了「鼠标穿透（点不到它）」之后，鱼身上就点不动了 ——
> 但要**从托盘图标的右键菜单**里取消它。

### 分身窗口（AI 助手）

- 右键桌宠选择「设置气泡字体」可修改头顶气泡字体与字号（8–16）；默认仍为微软雅黑 UI、11 号。
- 右键选择「设置分身人设」可补充分身的说话风格；留空恢复默认，修改从下一次对话生效。
- 右键勾选「本地保存分身聊天记录」后，完成或失败的对话会保存在配置目录的 `avatar-chat-history.json`，下次启动恢复。该功能默认关闭；关闭后保留已有文件，开启时如当前会话与旧记录都存在，需先清屏再开启以免覆盖。开启保存时，分身的「清屏」也会清空保存的会话。聊天记录是本地明文文件，请按需保管。

- **打开**：右键「分身（打开窗口）」；或「分身：总结剪贴板」
- **输入框**：`Enter` 发送 / `Shift+Enter` 换行 / `Ctrl+Enter` 也发送；框会随内容长高（1~5 行）
- **右上角按钮**：
  - 🌐 **看网页** —— 同一个窗口就地切成内嵌 Chromium
  - **自检** —— 看完整线路表，以及每条线的 DDG / Bing 可用性
  - **复制** —— 复制最后一条回复；**清屏**；**停止**（打断正在跑的任务）
- **过程可见**：任务进行中会实时显示「搜索：…」「写总结…」这类进度
- **翻来源**：任务完成后工具栏的 `◀ ▶` 带计数（如 `3/8`）在各来源间翻看
- **换模型**：`config.json` 里的 `task_model`（留空 = 跟 `ds_model` 一样）
- **最多来回几轮工具**：`task_max_rounds`（默认 4）

### 内嵌浏览器

- **地址栏什么都能吃**：网址、`D:\路径\文件.pdf`、本地 html、或者直接输搜索词；`Ctrl+L` 跳地址栏
- **键盘能直接打进网页**：登录表单、站内搜索都能正常打字
- **要登录的站点**：会把**网站自己的登录页**开到窗口里（扫码 / 验证码全归网站管），
  你登录完它自动重试继续干活，默认最多等 3 分钟（`login_wait_sec`）。
  桌宠**不做登录界面、不保存账号密码**
- **能开**：本地文件（html / pdf / txt / 图片）、下载文件、内置 PDF 阅读器、弹新窗口、全屏
- **Word / Excel / PPT**：Chromium 显示不了，直接交给系统默认程序打开（不会白屏）
- **敏感权限**：摄像头 / 麦克风一律拒绝并记录（隐私优先）
- **搜索引擎可切**：DuckDuckGo / Bing / 百度 / Google，会记住选择（`search_engine`）

### 护眼提醒（默认每 2 小时）

- 到点把你**真正开着**的窗口全部最小化，并放一块霸屏护眼大屏，**10 分钟后自动放回来**
- **逃生门**：大屏底部输入框默认已聚焦，直接打字 —— 输入「我在忙」「有事」「下次」「忙」「skip」
  之类的字眼就立刻放你走；输入别的它会吐槽你一句然后继续
- 只收你真正开着的窗口（排除它自己、桌面/任务栏等系统外壳、工具窗口、没标题的、已最小化的）
- 放回来很谨慎：逐个校验「进程 + 标题」都没变、且确实还处于最小化状态才恢复
- 中途重启也不怕（待放回的列表存在配置里）
- ⚠ 全屏视频 / 游戏也会被一起最小化；不想要就右键关掉总开关，或用 `eye_rest_*` 细调

### 动作点播

- 右键「动作」→「随机来一个」，或按分类点具体动作（卖萌 / 玩耍 / 情绪…）
- 开了视频动画后分类变成：点击回应 / 卖萌 / 玩耍 / 吃什么 / 时节 / 工作状态 / 文字 / 碎碎念
- 「回到待机」让它回去待机循环

### 视频动画 vs 手绘立绘

- 默认开视频动画（用 `anim/` 里的 106 个透明 webm）
- 右键「视频动画（透明 webm）」切换；或 `config.json` 里 `video_anim: false`
- `anim/` 没素材时会**自动退回**手绘立绘
- 视频与立绘共用本体窗口；窗口轮廓随角色和气泡更新，透明空隙可点击穿透，角色可直接点击和拖拽。
- 按显示器实际像素绘制，适配 125% / 150% 等显示缩放；立绘直接采样原图，避免先缩小再放大的模糊。Windows 本体窗口关闭系统背景、圆角及边框。
- 动画帧在后台使用 Lanczos 缩放和轻微锐化，保持角色透明轮廓；移动使用 8 毫秒精确定时器，同一帧的图像和轮廓会复用。动画帧率仍受原素材与解码速度限制。
- 锐化只作用于不透明内部，半透明外缘保持原有颜色，避免透明背景参与滤镜产生黑色光晕。
- 待机使用 5 秒的轻柔呼吸循环，保留耳朵、头发和裙摆细微运动。动作共用固定角色尺寸和脚底锚点，切换时旧画面只平移，扩大画布不会放大本体。
- 随机动作完整播放后歇 6～12 秒再自动接续，避免连续抽到同一个动作；碰撞后的揉头使用稳定姿态叠加小幅全身颤动，静止后持续约 1 秒，再接落地收尾和 3 秒停顿。
- 揉头反馈只在朝屏幕边缘快速撞击时触发（法向速度至少 900 像素/秒，近期移动至少 30 像素）；慢慢靠边、持续贴边、沿边滑动和微小鼠标抖动不会触发。
- 场景画布随完整动画展开，透明空白无底板、无边框且可点击穿透；水花、烟雾等半透明内容保留。碰撞按桌宠本体判断，待机、拖拽及碰撞动画的透明留白可以越过屏幕边缘。
- 高清动画放在 `anim/hd/`，有同名文件时优先播放 1280×720 版本。高清版从上游原始 720p 视频提取颜色细节，复用原版人工抠像的透明通道，并未把 360p 视频直接放大；原始 `anim/*.webm` 保留用于回退。
- 安装 `imageio-ffmpeg` 后，高清播放跳过浏览器逐帧 PNG 编码和 Base64 传输，按源视频的 24 FPS 播放；移动更新约 125 次/秒，实际屏幕显示受显示器刷新率限制。106 段高清素材约占 669 MiB，来源、帧数及校验值记录在 `anim/hd/manifest.json`。

### 天气 / 定位 / 城市

- 右键「查看天气」→ 走 `wttr.in`；有坐标就优先用坐标（比城市名准）
- 右键「🌍 用系统定位（授权）」→ 走 Windows 设备级定位，**会申请授权**；
  拿不到就退回 IP 粗略定位，气泡里会标明来源
- 「启动时自动更新城市（IP）」默认开：启动 7 秒后静默走一次，城市没变就完全不吭声
- 点「设置城市（手动）」会**自动关掉**自动刷新、并清掉旧坐标（否则天气会优先用旧坐标）

### 开机自启

- 右键「开机自启」→ 在**启动文件夹**里建 `大肥鱼桌宠.lnk`（**不是**注册表）
- 开启时先检测系统里是否已有入口，已有就认了、不建第二个
- 关闭时**只删自己建的那个**，你自己放的快捷方式不动

### 系统状态监控

- CPU > 90%、内存 > 95%、NVIDIA 显卡温度 > 80°C 时冒泡提醒（间隔 10 秒）
- 显卡需要 `pynvml`（`requirements.txt` 里已含）；没有 N 卡就自动跳过

### 代理 / 线路

- 会自动收集所有可用出口（直连 / 系统代理 / `proxy_list` / 本地常见端口），按目标自动选线：
  境外目标走境外线路，国内目标走国内线路
- 每条通道还会在两条线路上**同时打、谁先出结果用谁**，对冲线路抖动
- 想看完整线路表：分身窗口里输入「自检」，或点右上角「自检」

## 更换形象

把新的三视图（白底）放到某个目录，然后：

```bash
pip install -r requirements.txt   # 已经装过就跳过（这一步会把 Pillow 也装上）
set DAFEIYU_SRC=D:\你的素材目录
python tools/preprocess.py     # 白底抠图 + 统一高度
python tools/preprocess2.py    # 边缘去污 + 预乘 alpha 缩放出各尺寸
```

> **需要 Pillow**：这两个脚本用到了 `PIL`（Pillow），已经在 `requirements.txt` 里，
> 所以 `pip install -r requirements.txt` 会一起装上。
> 只装 `PySide6` 的话跑这两个脚本会报 `ModuleNotFoundError: No module named 'PIL'` ——
> 主程序的动画清晰度增强也使用 Pillow；未安装时可以运行，但会使用普通缩放。

高清动画生成工具 `tools/build_hd_animations.py` 另外需要 `numpy`、`opencv-python`、`imageio-ffmpeg`。
轻柔待机与碰撞姿态由 `python tools/build_soft_idle.py` 从原动画生成，输出原尺寸及高清版本；需要 Pillow 和 imageio-ffmpeg。原动画保留，过程检查记录写入项目旁的 `build/records/soft-idle-build`。
从[上游源视频包](https://github.com/PC2005-cloud/dsh-pet/releases/tag/assets-videos)提取与 `anim/` 同名的 mp4 后，可运行：

```powershell
python tools/build_hd_animations.py --sources "源视频目录" --output anim/hd --records "..\build/records\高清生成"
```

> 开源版改动：这两个脚本原来把作者的素材路径**写死**在代码里（`D:\` 盘下的私人文件夹），
> 现在改成从环境变量 `DAFEIYU_SRC` / `DAFEIYU_OUT` 读，输出默认写到本仓库的 `sprites/`。
> 不设环境变量直接跑会明确告诉你该怎么填，不会瞎猜路径。

## ❓ 常见问题（功能使用问题）

### 启动 / 窗口

**双击 `启动桌宠.bat` 没反应？**
三种可能：① 没装依赖 → 先 `pip install -r requirements.txt`；
② 它已经在跑了（见下一条）；③ `pythonw` 不带控制台，所以出错你看不见 ——
**改用命令行 `python 桌宠.py` 跑**，报错就会打出来。

**弹窗说「已经有一只大肥鱼在跑了」？**
单实例锁。同一时间只允许一只（两只同跑会互相覆盖配置）。
先看托盘 —— 它可能藏在托盘里；右键托盘图标 →「退出」，或去任务管理器结束 `pythonw.exe` / `大肥鱼桌宠.exe`。

**鱼跑到屏幕外面 / 找不到了？**
右键**托盘图标** →「回到屏幕内」。实在不行关掉它，把 `config.json` 里的 `x` / `y` 改成 `null` 再启动。

**鱼点不动了，怎么点都没反应？**
多半开了**鼠标穿透**。右键**托盘图标** →「鼠标穿透（点不到它）」取消勾选。

**装到 `C:\Program Files` 之后设置存不下来？**
新版不会有这个问题 —— 配置和 Key 默认在 `%APPDATA%\dafeiyu-pet\`，那目录一定可写。
除非你放了 `portable.txt` 强制便携模式，那才会回到程序目录。

**换电脑 / 换了 Windows 账户以后 Key 没了？**
**这是设计如此。** Key 用 Windows DPAPI 按当前用户加密，换机器或换账户**解不开** —— 这正是它安全的原因。
到新机器上右键「设置 Key」重填一次即可；其它设置照常跟着 `config.json` 走。

### Key / 分身

**鱼老说「先设置 Key 我才能干活！」？**
还没填 Key，或填的是模板占位符。右键 →「设置 Key（还没填 ← 点这里）」，填完气泡会报「Key 验过了 ✓」，**不用重启**。

**提示「Key 被拒了（401）」？**
Key 本身不对。去 <https://platform.deepseek.com> 重新复制**完整**的 Key（一般 `sk-` 开头），
注意别漏字符。程序会自动去掉首尾空格、引号和 `Bearer ` 前缀，但改不了的字符救不了。也确认下账号额度。

**提示「Key 没验成（超时），但不影响使用」？**
网络到不了 API（代理 / 防火墙 / 断网）。这个提示**不会**清掉你已存好的 Key，网络恢复就能用。
可以右键「测试 Key 连通性」再验一次。

**分身说「上一件还没干完」？**
一次只跑一个任务。点分身窗口的「停止」打断它，或者等它跑完。

**分身搜不出东西 / 说被人机验证拦住？**
DuckDuckGo 有时会甩人机验证页。这时分身会：① 自动改用 Bing 继续搜（照常出结果）；
② 被拦后 **10 分钟内**不再硬碰 DDG；③ 若开了 `browser_search`，会用内嵌真浏览器再试一次。
想看当前线路状况，在分身窗口里输入「**自检**」。
想看 DDG 内容就点窗口里的「🌐 看网页」用真浏览器打开、手动过掉验证。

**想让分身用更强的模型？**
`config.json` 里把 `task_model` 改成你要的模型名（留空 = 跟 `ds_model` 一样），保存即时生效。

**分身太啰嗦，想短一点？**
分身的人设和长度写在 `桌宠.py` 的 `TASK_SYSTEM` 里（默认「300 字内」）；
鱼自己的气泡台词在 `DS_SYSTEM`（默认「每句话不超过 25 字」）。改完重启生效。

### 内嵌浏览器

**内嵌浏览器一片空白 / 起不来？**
确认 `config.json` 里 `webengine_no_sandbox` 是 `true`（部分机器上 Chromium 自带沙箱起不来）。
还不行就看命令行输出里 `内嵌浏览器不可用:` 后面的原因 —— 多半是 PySide6 的 WebEngine 组件没装上。

**打开 Word / Excel 白屏？**
Chromium 显示不了 Office 格式。新版会**直接交给系统默认程序打开**；
没弹出来说明这台机器没装 Office / WPS。

**键盘打不进网页？**
登录表单和站内搜索都支持直接打字。碰到个别不吃键盘的控件，按 `Ctrl+L` 回地址栏再点回页面即可。

**网站要登录怎么办？**
会把**网站自己的登录页**开到窗口里，你正常登录（扫码 / 验证码都行），登录完它自动重试继续干活。
登录状态存在浏览器 profile 里，下次不用再登。桌宠**不保存**你的账号密码。

### 其它功能

**视频动画不播，还是手绘立绘？**
可能 `anim/` 里没素材（会自动退回立绘），或 `video_anim` 是 `false`。
播放器加载或解码失败时保留立绘。视频帧在本体窗口内绘制，不再叠放额外的浏览器窗口。

**水枪、道具或场景被桌宠周围的框裁掉？**
动画按完整的 16:9 源画幅绘制，并让视频角色和原立绘保持相同尺寸。
拖拽时固定视频角色的位置和大小，避免悬空反馈动画看起来忽大忽小。
透明区域继续点击穿透，不显示背景或边框。所有动画共用完整场景适配：靠近屏幕边缘时自动调整位置，
画幅超过屏幕可用区域时等比例缩放；行走、拖拽和甩动也会给整个场景留出空间，无需手动拖到屏幕中间。

**查不到天气？**
多半 `city` 还是占位符「你的城市，例如：北京」。右键「设置城市（手动）」填个真城市；
或者让它自动定位（右键「🌍 用系统定位（授权）」，或开着 `auto_locate_city` 走 IP）。

**护眼提醒把我的全屏游戏 / 视频最小化了？**
目前没有游戏白名单，全屏也会被一起收。不想要就右键关掉「护眼提醒（每 2 小时）」，
或用 `eye_rest_minimize_windows: false` 让它只提醒、不动你的窗口。

**护眼大屏怎么立刻结束？**
大屏底部输入框默认已聚焦，直接打字 —— 输入「我在忙」「有事」「下次」「忙」「skip」就立刻放你走。

**开机自启没生效？**
它是在**启动文件夹**里建 `大肥鱼桌宠.lnk`（不是注册表）。如果你的启动文件夹被重定向
（例如到 `D:\Programs\Startup`），去那个目录看；另外系统「设置 → 应用 → 启动」里被禁用了也不会生效。

**改了 `config.json` 怎么没生效？**
城市 / 模型 / 主题这些改完保存就该立刻生效（会气泡提示「配置已自动更新」）。
没反应的话，先用右键「我的配置存在哪？（看路径）」确认你改的是**当前真正在用的那个文件**。
只有改 `桌宠.py` 里的代码常量才需要重启。

**提示找不到浏览器？**
分身的外部 headless 通道需要一个 Chromium 内核浏览器，它会查注册表和常见安装位置。
都没有的话，用 `chrome_path` 写死全路径，或把目录加进 `chrome_search_dirs`
（默认是空的，**不会去扫你的硬盘**）。

**程序目录里的 `debug.log` 是什么？**
**不是桌宠写的** —— 是搜狗输入法往进程里写的，删掉还会再生成，已在 `.gitignore` 里。

**打包出来的 exe 被杀毒软件报毒？**
PyInstaller 产物的常见误报，加信任即可。

**想彻底重置所有设置？**
关掉桌宠，把 `%APPDATA%\dafeiyu-pet\` 整个删掉（`config.json` + `key.bin`），下次启动会重新生成。
⚠ 这会连 Key 一起删掉，需要重新填。

**想换成自己的形象？**
见下面「更换形象」一节。
